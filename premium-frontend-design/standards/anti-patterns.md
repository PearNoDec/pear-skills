# Anti-Patterns and AI-Template Detection

## Generic visual defaults to avoid

- Purple-blue gradients without brand justification
- Random glowing background spheres
- Excessive glassmorphism
- All-card page architecture
- Excessive pill buttons
- Every section centered
- Every section using the same three-column grid
- Generic startup hero composition
- Decorative labels with no informational role
- Gradient buttons everywhere
- Extreme rounded corners
- Low-contrast gray text used for most content
- Unnecessary tiny type

## Generic SaaS patterns to challenge

- Text left / dashboard right on every hero
- Fake dashboard screenshots
- Feature-card walls
- Four identical statistic cards
- Pricing design that hides differences
- Product UI with marketing-site visual effects

## Generic admin patterns to challenge

- Converting all data into cards
- Giant headings consuming workspace
- Decorative charts without operational meaning
- Low information density
- Hidden actions revealed only by hover
- Weak table and filter design

## Brand-specificity test

Ask:

- Does the composition reflect this company's actual value proposition?
- Is there a recurring visual signature?
- Are colors doing more than following a trend?
- Are visuals related to actual content?
- Could the company name be swapped with a random startup without redesigning anything?

If the design is interchangeable, improve specificity.

## Card test

Before creating a card, ask:

- Does this information need a bounded container?
- Does the container communicate grouping, interactivity or hierarchy?
- Would typography, spacing, rules or layout communicate the structure better?

Do not use cards as the default solution to every layout problem.

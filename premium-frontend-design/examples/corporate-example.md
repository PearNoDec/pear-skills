# Example - Corporate Website

## Input

"Redesign our cybersecurity company's homepage. It currently looks generic and we want it to feel more enterprise-grade."

## Mode

CORPORATE with technology-product characteristics.

## Direction

- Brand tone: authoritative, precise, technical
- Density: medium
- Motion: medium
- Hero: strong typography + live security-network visualization
- Signature: grid / scanning-line system used throughout the page
- Trust: customer scale, compliance and case outcomes near key claims

## Avoid

- Generic hacker stock imagery
- Neon green-on-black everywhere
- Three-column security feature cards repeated through the page
- Empty futuristic slogans without concrete value

## Page rhythm

Hero -> proof -> problem landscape -> solution architecture -> product visualization -> outcomes -> customer story -> security standards -> CTA -> branded footer.

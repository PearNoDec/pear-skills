# General / Creative Frontend Mode

Use when corporate, SaaS or admin conventions do not clearly dominate.

## Priorities

Balance identity, content clarity, UX, visual hierarchy, interaction, responsive behavior and maintainability. No single one of these may be traded to zero for another — that trade is what separates an experimental site that works from one that only photographs well.

## Creative freedom

The browser can be treated as an interactive visual canvas when the context supports it: editorial typography, layered composition, dynamic grids, SVG motion, Canvas, WebGL, 3D, shaders, scroll-linked storytelling, interactive type, perspective, masking, grain and texture.

The selection rule: **choose the technique from what the content is, not from what is technically possible.** A shader because the product is about light is a decision; a shader because shaders are impressive is decoration with a large performance bill.

`standards/anti-patterns.md` § *Where a signature actually comes from* applies here more than anywhere else — creative freedom without a source is how work ends up looking like every other award-site template.

## Guardrails

Every experimental choice must preserve comprehension, navigation clarity, keyboard access, responsive behavior, readable text, a performance fallback and reduced-motion behavior.

If the experimentation makes the primary task harder, reduce it. If it cannot be reduced without losing the idea, the idea was wrong for this surface.

# General / Creative Frontend Mode

Use this mode when corporate, SaaS or admin conventions do not clearly dominate.

## Priorities

Balance:

- Identity
- Content clarity
- UX
- Visual hierarchy
- Interaction
- Responsive behavior
- Maintainability

## Creative freedom

The browser may be treated as an interactive visual canvas when the context supports it.

Possible techniques:

- Editorial typography
- Layered composition
- Dynamic grids
- SVG motion
- Canvas
- WebGL
- 3D
- Shader effects
- Scroll-linked storytelling
- Interactive type
- Perspective
- Masking
- Grain and texture

Do not use advanced rendering simply because it is technically possible.

## Guardrails

Every experimental choice must preserve:

- Basic comprehension
- Navigation clarity
- Keyboard access
- Responsive behavior
- Readable text
- Performance fallback
- Reduced-motion behavior

If visual experimentation makes the main task harder, reduce it.
